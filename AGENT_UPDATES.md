# AGENT_UPDATES

Chronological, append-only status log for agents. Use the helper scripts in `scripts/` to add entries.

Format:
- ISO8601 UTC timestamp — AgentName: message

Example:
2026-03-21T12:34:56Z — GPT: Created pre-commit hook

Notes:
- Keep entries short and factual.
- This file is intentionally append-only to provide an audit trail for agent activity.
